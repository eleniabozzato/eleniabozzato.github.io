# eleniabozzato.com

Static site for Elenia Bozzato, generated by `build.mjs` from `src/` (templates, texts in `src/i18n`, data in `src/data`) and `assets/`. English at the root, Italian under `/it/`. No runtime dependencies.

```sh
make dependencies   # once: npm install + Chromium for Playwright
make build          # src/ -> dist/
make start          # build and serve dist/ on http://localhost:8080
make check          # build + internal links
make visual         # screenshot comparison with a base ref (BASE=<ref>)
```

Release: merge into `main`. `.github/workflows/deploy.yml` builds `dist/` and publishes it with GitHub Pages (Settings > Pages > Source: GitHub Actions).

See `CLAUDE.md` for the structure and the rules.
